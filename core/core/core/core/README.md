# 🐟 HobZ

نظام المحاكاة التنبؤية المتقدم

## المميزات
- محرك سببي يفهم العلاقات بين الأسباب والنتائج
- ذاكرة عالمية تتعلم من كل محاكاة
- فريق وكلاء ذكي (محلل، ناقد، متنبئ)
- واجهة ويب سهلة الاستخدام

## كيفية الاستخدام
1. أدخل السيناريو
2. أضف العوامل المؤثرة
3. اضغط "تشغيل المحاكاة"
4. شاهد النتائج والتفسيرات
